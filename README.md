# BOXING LEGACY — protótipo Godot

## Abrir o projeto
1. Baixe o projeto pelo botão **Code → Download ZIP**.
2. Extraia a pasta no dispositivo.
3. No Godot, importe o arquivo `project.godot`.
4. Abra o projeto e pressione Executar.

## Protótipo atual
- Arena 3D simples com câmera em perspectiva lateral.
- Dois lutadores estilizados criados com formas 3D.
- Controles de toque: mover, esquivar, jab, direto e gancho.
- Adversário com IA básica.
- Barras de vida e resistência e cronômetro.
- Renderizador Compatibility, escolhido pensando em dispositivos móveis.

## Estado
Esta é a primeira base jogável, ainda não validada em execução no Godot. Modelos, animações, colisões, áudio, interface adaptativa e exportação APK serão refinados nas próximas etapas.
